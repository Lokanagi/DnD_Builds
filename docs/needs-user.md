Проверил сам: все переходы в приложении захардкожены (`navigate("/")`, статичные `NavLink to=`), ниоткуда не берём путь из пользовательского ввода — реально не эксплуатируется в этом коде. - **level_override**: в схеме есть поле для ручной правки уровня персонажа мастером (на случай расхождения с листом/опытом), но UI для него не делал — пока расхождение только подсвечивается на странице "Опыт".
