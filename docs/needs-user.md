Проверил сам: все переходы в приложении захардкожены (`navigate("/")`, статичные `NavLink to=`), ниоткуда не берём путь из пользовательского ввода — реально не эксплуатируется в этом коде. - **Supabase: план и лимиты**: сейчас бесплатный тир — для одной кампании с несколькими игроками скорее всего хватит, но если упрётесь в лимиты (одновременные подключения и т.п.) — апгрейд плана (платный) только твоё решение.
- **level_override**: в схеме есть поле для ручной правки уровня персонажа мастером (на случай расхождения с листом/опытом), но UI для него не делал — пока расхождение только подсвечивается на странице "Опыт".
- **Поиск D&D на русском — покрытие словаря не 100%**: встроен словарь частых терминов (гоблин→goblin, зелье→potion и т.п.) для первого шага поиска по open5e — если слова нет в словаре, ищи по-английски, сработает всегда.
- **dnd.su-статблок — не для каждого монстра/предмета найдётся**: сопоставление идёт по английскому имени из open5e через снэпшот карты dnd.su (сайт их не даёт API, собрал карту id↔имя из их sitemap.xml один раз при сборке). Если конкретной твари/предмета на dnd.su нет под тем же именем — показывается запасной вариант на основе open5e (русские подписи полей, но проза действий — на английском, т.к. у open5e только английский текст).
- **dnd.su-карта может устареть**: собрана один раз (12.10.2026) из их sitemap — если на сайте появятся новые монстры/предметы, их не найдёт, пока карту не пересоберу.
